ServiceMonitors/PodMonitors are scraped automatically — no labels needed.

NOTE: on a FIRST install with plain Helm, the OpenTelemetryCollector resources
race the operator webhook and the install can fail. Either install once with
--set collectors.enabled=false and upgrade with it enabled, or simply re-run
`helm upgrade --install`. ArgoCD with retries converges on its own (the chart
README has the required Application settings: ServerSideApply=true + retry).
{{- else }}

collected. Once the OTel operator is running, enable them:
  helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} --reuse-values --set collectors.enabled=true
{{- end }}
